# Health Insurance Data Analysis and Machine Learning

## 📊 Project Overview

This project focuses on the analysis of health insurance data using **Exploratory Data Analysis (EDA), statistical techniques, dimensionality reduction, and machine learning**.

The project explores the characteristics and relationships within a health insurance dataset and applies multiple machine learning algorithms to build and compare predictive models.

## 🎯 Objectives

* Perform exploratory analysis of health insurance data.
* Identify important patterns, relationships, and trends in the dataset.
* Analyze feature correlations and distributions.
* Apply **Principal Component Analysis (PCA)** for dimensionality reduction.
* Train and compare multiple machine learning classification algorithms.
* Evaluate model performance using appropriate classification metrics.
* Identify suitable models for the given dataset.

## 🔍 Exploratory Data Analysis

The project includes several data analysis techniques:

* Data preprocessing and cleaning
* Statistical summaries
* Feature distribution analysis
* Histograms
* Box plots
* Correlation analysis
* Feature relationship analysis
* Outlier analysis
* Visualization of important dataset characteristics

## 🧠 Machine Learning Algorithms

Multiple classification algorithms were explored and compared, including:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest
* Extra Trees Classifier
* Naive Bayes
* AdaBoost
* Gradient Boosting
* XGBoost
* CatBoost

The models were evaluated and compared to understand their effectiveness on the health insurance dataset.

## 📉 Principal Component Analysis

**Principal Component Analysis (PCA)** was applied as a dimensionality-reduction technique.

PCA helps transform the original feature space into a smaller set of principal components while retaining important information from the dataset.

The project examines the effect of dimensionality reduction on the machine learning workflow.
